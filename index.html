اسحب الصور هنا أو اضغط للاختيار

JPG • PNG • WebP • GIF (أول إطار) • BMP — تدعم سحب متعدد ولصق بـ Ctrl+V

🔍 كيف نتأكد أنها نظيفة 100%؟

  1. لا ننسخ الملف: نرسم الصورة على <canvas> كبكسلات فقط.
  2. إعادة ترميز: نولّد ملفاً جديداً بـ canvas.toBlob() — المتصفح يكتب فقط بكسلات + ترويسة أساسية نظيفة، بدون APP1/APP13/COM/tEXt/eXIf.
  3. تجاهل التوجيه المخزن: نطبق التدوير بصرياً ثم نحذف وسم Orientation.
  4. اسم جديد + تاريخ جديد: لا توجد بصمة اسم أو timestamp قديم.
  5. فحص بعد التنظيف: الموقع يفحص الملف الناتج بباحث markers ويعرض لك "نظيف ✅".
ما الذي يُحذف بالضبط؟
  • GPS (خط الطول/العرض/الارتفاع)، EXIF (كاميرا، عدسة، سرعة، ISO، تاريخ التصوير)
  • XMP (Adobe / Lightroom history)، IPTC (مصور، حقوق، كلمات)
  • Thumbnail مضمّن، تعليق JPEG COM، قطع PNG النصية tEXt/iTXt/zTXt/eXIf
  • ICC profile (نعيد بناء بألوان sRGB الافتراضية)، Software / Artist tags
